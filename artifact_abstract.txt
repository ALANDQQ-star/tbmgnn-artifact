Artifact Abstract

This artifact consists of software, cached data, trained models, configuration files, shell scripts, claim checking scripts, frozen intermediate inputs, and reference outputs for evaluating TBMGNN. The software is submitted as Python source code with released PyTorch model checkpoints and Linux shell scripts. 

We would like to request for evaluating three badges, i.e., Available, Functional and Reproduced. Basically, the artifact supports the manuscript's following results: (1) parameter selection and reliability calibration experiments (Table 3); (2) bot node detection performance evaluation under complete-graph and same-sample settings, including the split analysis (from Table 4 to Table 8); (3) ablation analysis (Table 9).

The artifact runs on Ubuntu 22.04 or Ubuntu 24.04. The required system packages are Python 3, `python3-venv`, and `pip`. The Python dependencies installed by `install.sh` include PyTorch, PyTorch Geometric, NumPy, pandas, SciPy, scikit-learn, NetworkX, dpkt, and tqdm. A CPU machine with at least 16 gigabytes (GB) RAM is sufficient for the checked evaluation. A CUDA GPU is useful for retraining models. The archive consumes about 3.7 GB of disk space when compressed while 10 GB after unpacking. The Internet access is required during installation to download Python wheels; the checked experiments use cached inputs.

The artifact can run on public research infrastructure. We recommend WSL2 on a standard workstation, CloudLab, Chameleon, SPHERE, or an equivalent Ubuntu Linux VM with at least 16 GB RAM. The checked evaluation consists of the search, CTU-13 reproduction, transfer, Table 5 comparison, and ablation/statistics scripts. On the tested WSL setup, each search and CTU-13 script completes in about two minutes, while the transfer, Table 5, and ablation/statistics scripts use bundled caches, frozen same-sample evidence, and released model outputs. Moreover, baseline retraining and TBMGNN weight retraining can take several hours, with the duration varying based on specific conditions.

The packaged data and model files are included for evaluation. External dataset paths may be supplied with `CTU13_DATA_DIR`, `ISCX_DATA_DIR`, and `CIC_CSV`. The artifact will be publicly released after artifact evaluation. There are no constraints in this artifact that necessitate special handling, such as proprietary components, sensitive datasets, restricted hardware, geolocation requirements, embargoed materials, or security-sensitive code.
