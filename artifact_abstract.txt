Title: TBMGNN: Transferable Bot Detection Method Based on Multi-View Graph Neural Networks

Requested badges: Available, Functional, Reproduced

Artifact abstract:

This artifact consists of software, cached data, trained models, configuration files, shell scripts, claim checking scripts, frozen intermediate inputs, and reference outputs for evaluating TBMGNN. The software is submitted as Python source code with released PyTorch model checkpoints and Linux shell scripts.

The requested badges are Available, Functional, and Reproduced. The artifact supports the paper's CTU-13 complete-graph bot detection results, the comparison with TRUSTED, Bot-DM, Bot-AHGCN, and BWGNN, the cross-dataset transfer experiments on ISCX Botnet 2014 and CICIDS2017, the reliability-selection parameter search, the split analysis, the view-selection ablation, the energy-margin analysis, and the statistical significance analysis.

The artifact runs on Ubuntu 22.04 or Ubuntu 24.04. The required system packages are Python 3, `python3-venv`, and `pip`. The Python dependencies installed by `install.sh` include PyTorch, PyTorch Geometric, NumPy, pandas, SciPy, scikit-learn, NetworkX, dpkt, and tqdm. A CPU machine with at least 16 GB RAM is sufficient for the checked evaluation. A CUDA GPU is useful for retraining models. The archive is about 3.7 GB compressed and uses about 10 GB after unpacking, before Python packages and generated outputs. Network access is used during installation to download Python wheels; the checked experiments use cached inputs.

The artifact can run on public research infrastructure. We recommend WSL2 on a standard workstation, CloudLab, Chameleon, SPHERE, or an equivalent Ubuntu Linux VM with at least 16 GB RAM. The checked evaluation consists of the search, CTU-13 reproduction, transfer, and ablation/statistics scripts. On the tested WSL setup, the search and CTU-13 scripts each complete in under two minutes, and the transfer and ablation/statistics scripts use bundled caches and frozen outputs. Baseline retraining and TBMGNN weight retraining can take several hours.

The packaged data and model files are included for evaluation. External dataset paths may be supplied with `CTU13_DATA_DIR`, `ISCX_DATA_DIR`, and `CIC_CSV`. The artifact will be publicly released after artifact evaluation. Proprietary components, sensitive datasets, restricted hardware, geolocation requirements, embargoed materials, and security-sensitive live deployment components are not needed.
