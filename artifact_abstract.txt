Title: TBMGNN: Transferable Bot Detection Method Based on Multi-View Graph Neural Networks

Requested badges: Available, Functional, Reproduced

Artifact abstract:

This artifact consists of software, bundled data, trained models, configuration files, shell scripts, claim-level check scripts, frozen intermediate inputs, and reference outputs for evaluating TBMGNN. The software is submitted as Python source code with released PyTorch model checkpoints and WSL/Linux shell scripts. Containers, virtual machine images, live services, mechanized proofs, and special infrastructure are not needed.

The artifact supports the paper's CTU-13 complete-graph bot detection results, the comparison with TRUSTED, Bot-DM, Bot-AHGCN, and BWGNN, the cross-dataset transfer experiments on ISCX Botnet 2014 and CICIDS2017, the reliability-selection parameter search, the split analysis, the view-selection ablation, the energy-margin analysis, and the statistical significance analysis. The executable mapping is `claims/ctu/run.sh`, `claims/transfer/run.sh`, `claims/search/run.sh`, and `claims/ablation/run.sh`. Optional baseline retraining and TBMGNN weight retraining scripts are included outside the checked evaluation workflow.

The artifact runs on Ubuntu 22.04 or Ubuntu 24.04, including WSL2. The required system packages are Python 3, `python3-venv`, and `pip`. The Python dependencies installed by `install.sh` include PyTorch, PyTorch Geometric, NumPy, pandas, SciPy, scikit-learn, NetworkX, dpkt, and tqdm. A CPU machine with at least 16 GB RAM is sufficient for the checked evaluation. A CUDA GPU is useful for optional retraining workflows. The archive is about 3.7 GB compressed and uses about 10 GB after unpacking, before Python packages and generated outputs. Network access is used during installation to download Python wheels; the checked experiments use bundled inputs.

The artifact can run on public research infrastructure. We recommend WSL2 on a standard workstation, CloudLab, Chameleon, SPHERE, or an equivalent Ubuntu Linux VM with at least 16 GB RAM. The checked evaluation consists of the search, CTU-13 reproduction, transfer, and ablation/statistics scripts. On the tested WSL setup, the search and CTU-13 scripts each complete in under two minutes, and the transfer and ablation/statistics scripts use bundled caches and frozen outputs. Optional baseline retraining and TBMGNN weight retraining can take several hours.

The packaged data and model files are included for evaluation. External dataset paths may be supplied with `CTU13_DATA_DIR`, `ISCX_DATA_DIR`, and `CIC_CSV`. Proprietary components, sensitive datasets, restricted hardware, geolocation requirements, embargoed materials, and security-sensitive live deployment components are not needed. Generated outputs are written under `artifact/results/generated` and checked against `artifact/results/reference`. The artifact will be publicly released after ACSAC artifact evaluation.
